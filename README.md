# Guillermo

Embedded and communications systems engineer. I write low-level C and C++ and bare-metal firmware.
B.Sc. in Physics with a computational focus, based in Spain.

**Stack:** C, C++, Rust, Python / PyTorch, Linux

## Selected work

- [balloc](https://github.com/gcpino/balloc): arena, pool and heap allocators in C, benchmarked against glibc malloc.
- [aes256](https://github.com/gcpino/aes256): single-header C11 AES-256 (ECB, CBC, CTR) and AES-256-GCM AEAD, verified against FIPS 197 and NIST SP 800-38A/D vectors.
- [SentinelMesh](https://github.com/gcpino/SentinelMesh): assurance-oriented C11 decentralized mesh networking daemon with zero steady-state heap allocations, DSDV routing, and X25519/ChaCha20 session security.
- [sdr](https://github.com/gcpino/sdr): FM broadcast demodulator in about 600 lines of C, from IQ samples to WAV.
- [c-infer](https://github.com/gcpino/c-infer): neural-network inference engine in pure C11. No BLAS, no allocation in the forward pass, PyTorch exporter, parity tests.
- [PINN](https://github.com/gcpino/PINN): physics-informed neural network for the 1D heat equation, validated against the analytical solution.
- [spsc](https://github.com/gcpino/spsc): cache-line-aligned lock-free single-producer single-consumer ring buffer in Rust.
