B.Sc. in Physics with a computational focus, based in Spain.

**Stack:** C, C++, Python / PyTorch, Linux

## Selected work

- [c-infer](https://github.com/gcpino/c-infer): neural-network inference engine in pure C11. No BLAS, no allocation in the forward pass, PyTorch exporter, parity tests.
- [balloc](https://github.com/gcpino/balloc): arena, pool and heap allocators in C, benchmarked against glibc malloc.
- [sdr](https://github.com/gcpino/sdr): FM broadcast demodulator in about 600 lines of C, from IQ samples to WAV.
- [PINN](https://github.com/gcpino/PINN): physics-informed neural network for the 1D heat equation, validated against the analytical solution.
